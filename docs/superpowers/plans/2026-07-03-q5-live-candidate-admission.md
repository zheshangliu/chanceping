# Q.5 Live Candidate Admission Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix live candidate admission so relevant raw results from dynamic radar query families can enter opportunity cards without hardcoding Golden 8 industries.

**Architecture:** Keep RadarVersionSpec as the source of strategy. Add a generic keyword-pack builder derived from RadarVersionSpec/queryFamilies, then teach ruleFilter to use relaxed semantic admission for live radar-version candidates while preserving URL safety, exclusions, deduplication, low-action handling, and anti-overclaim card labels.

**Tech Stack:** TypeScript, tsx verification scripts, existing SearchOrchestrator/ruleFilter/providerRegistry test patterns.
