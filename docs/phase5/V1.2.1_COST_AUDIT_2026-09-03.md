## No double counting

The hybrid run's aggregate `requestCount.tikhub` row is a cross-check only. It
is not added to the endpoint rows. Some historical benchmark scripts incremented
their counters only after successful responses, while still writing failed
attempts into result arrays; therefore a complete historical request ledger
cannot be reconstructed without a provider billing export.
