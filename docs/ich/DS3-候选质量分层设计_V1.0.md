# DS3 候选质量分层设计 V1.0

## 1. 目标与边界

DS3 对 DS2 的候选样本进行质量预审，输出分数、质量等级和人工复核原因。它不是正式发布器，不会自动批准、导入或修改机会库。

## 2. 评分维度

- 详情页、标题、主办方、截止日期、地区、分类和快照哈希；
- 来源角色（primary/secondary/discovery）；
- 标题中的非遗相关性和行动性提示；
- 已知模板标记和详情 URL 重复检查。

分数只用于排序，不替代逐字段人工确认。任何候选都保持 `formal_publish_blocked=true`，决策只能是 `review_required` 或 `reject`。

## 3. 门禁

进入 DS3：DS2 运行记录存在且正式库哈希未变化。退出 DS3：每条候选都有质量评估、理由和人工复核状态，0 条自动批准，正式库哈希仍不变。
