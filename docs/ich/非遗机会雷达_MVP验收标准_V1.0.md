# 非遗机会雷达 MVP 验收标准 V1.0

状态：阶段 5A 冻结
基准日期：2026-07-24

## 1. 数据规模

| 指标 | 通过标准 |
|---|---:|
| 当前有效机会 | ≥30 |
| 比赛与作品征集 | ≥5 |
| 展会、市集与展销 | ≥5 |
| 采购、项目与活动需求 | ≥5 |
| 渠道入驻与品牌合作 | ≥3 |
| 政策、资金与人才计划 | ≥3 |
| 国际交流与海外机会 | ≥3 |
| 历史机会 | ≥5 |
| 地区层级 | ≥3 |
| L1/L2 主要来源比例 | ≥80% |

数量统计只计算 `is_published=true`、工作流为 `published`、状态属于 `active`、`closing_soon` 或 `long_term`，且在基准时间仍可行动的记录。

## 2. 单条发布门槛

每条公开记录必须满足：

- 唯一 `id` 和 `slug`；
- 标题、摘要、主分类和主办方非空；
- 恰好一个主要来源；
- 主要来源使用 HTTP(S) 且实际可访问；
- 分类状态为 `confirmed`；
- 验证状态不为 `rejected` 或 `conflicting`；
- 资格对象有原文依据；
- 截止日期或长期有效状态有原文依据；
- 地区与参与资格地区不混淆；
- 行动方式明确；
- 最后核查时间存在；
- 工作流为 `published`；
- 当前记录未过期、未取消、未失效。

## 3. 真实性与证据

- 金额、费用、资格和日期不得推测；
- 未公开费用不得显示为免费；
- 未确认布尔值不得强制写成 `false`；
- 能追溯到主办方或第一方页面时优先替换；暂时无法追溯的具体转载线索可以发布，但必须标为部分核验并提示用户申请前复核；
- 结果公告、名单公示和活动回顾不得进入当前机会；
- 同一机会的多来源应合并；
- 每条机会保留核验说明和来源检查时间。

## 4. 产品路径

- `/ich` 首屏 SSR 包含真实机会卡；
- 六类筛选均有结果；
- 关键词搜索能命中标题、主办方或标签；
- 地区筛选至少覆盖三个层级；
- `/ich/history` 不混入当前记录；
- 详情页显示状态、主办方、资格、时间、地区、价值、要求、行动方式和来源；
- 已截止、取消、失效记录不显示行动按钮；
- Sitemap 只包含公开页面；
- 手机端、桌面端和微信内置浏览器基本可用；
- 来源提交仍只进入隔离审核队列。

## 5. 工程与回归

- 阶段 5 导入支持 dry-run；
- 每批导入有批次号、清单、统计和备份；
- 回滚可恢复导入前正式数据；
- `npm run typecheck` 通过；
- `npm run verify:v15:e2e` 通过；
- `npm run verify:v15`、`verify:v16`、`verify:all` 存在并通过；
- ICH 阶段 1—5 全部通过；
- AI Events、Business 和 Welfare 无回归。

## 6. 判定

- 任一分类数量不足：FAIL；
- 当前有效总数不足 30：FAIL；
- L1/L2 比例不足 80%：FAIL；
- 存在假数据、已截止冒充当前或自动发布：FAIL；
- 数据达标但浏览器或全量回归未通过：PARTIAL，不得发布；
- 所有条目通过：PASS，可提交产品负责人审阅发布范围。
