# 非遗机会雷达阶段 5 测试用例 V1.0

状态：阶段 5A 冻结

## A. 数量与覆盖

1. 当前有效公开记录不少于 30；
2. 六类分别满足 5/5/5/3/3/3；
3. 至少三个地区层级有真实结果；
4. L1/L2 主要来源比例不少于 80%；
5. 历史记录不少于 5。

## B. 单条契约

1. 缺少标题、摘要、主办方或来源时拒绝；
2. 零个或多个主要来源时拒绝；
3. 非 HTTP(S) 来源拒绝；
4. 重复 id 或 slug 拒绝；
5. 未审核记录不得公开；
6. `workflow.state` 与 `is_published` 不一致时拒绝；
7. 未知金额为 `null`，免费只有在原文明确时才允许为 `0`；
8. 日期、地区和资格枚举合法。

## C. 时间与状态

1. 未来开放进入 `opening_soon`；
2. 当前可行动进入 `active`；
3. 距截止不超过 14 天进入 `closing_soon`；
4. 明确长期招募才允许 `long_term`；
5. 截止后进入 `expired`；
6. 活动结束进入 `ended`；
7. 取消进入 `cancelled`；
8. 无法确认状态不进入当前列表；
9. 来源失效且无替代证据不进入当前列表。

## D. 去重

1. 同一官方 URL 重复导入必须识别；
2. 同标题、主办方、截止日期的转载必须提示高概率重复；
3. 同一机会多来源合并后只显示一张卡；
4. 不同年份、批次、城市或采购包不得误合并；
5. 低等级来源不得覆盖高等级来源的核心字段。

## E. 导入与回滚

1. dry-run 不修改正式文件；
2. dry-run 输出新增、更新、重复、跳过、失败和归档；
3. 无效候选不阻断有效记录的报告生成，但正式导入必须显式处理失败；
4. 正式导入前生成备份；
5. 导入批次写入 `source_import_batch`；
6. 回滚恢复原文件内容和数量；
7. 页面读取失败时不自动写 seed。

## F. 页面与 API

1. `/api/public/ich/opportunities` 返回不少于 30 条当前记录；
2. 六类查询分别有结果；
3. 关键词和地区组合筛选正确；
4. 分页无重复或遗漏；
5. 未发布详情返回 404；
6. `/ich` 初始 HTML 含真实标题；
7. `/ich/history` 只展示历史；
8. 详情页包含主要来源和最后核查时间；
9. Sitemap 不含未发布、撤回和归档详情；
10. 来源提交不能直接创建正式机会。

## G. 回归与浏览器

1. 桌面端首页、筛选、详情、历史通过；
2. 手机端首页、筛选、详情、提交来源通过；
3. 匿名不能访问内部审核 API；
4. AI Events 当前/历史和详情无回归；
5. V1.5/V1.6 自定义雷达主链路无回归；
6. Business 和 Welfare 公开入口/API 无回归；
7. 全量验证命令通过。
