所有样本均保留为 `candidate_review`，并强制 `formal_publish_blocked=true`。这表示“可以继续人工核验”，不表示“可以展示为正式机会”。

## 3. 关键发现

1. 9 个样本均回溯到具体详情页，未把来源首页当作机会详情页。
2. 未检测到 DS0 已知模板标记，也未发现相同详情 URL 或归一化标题重复。
3. 5 个样本没有明确截止字段，均保持未确认；没有用发布日期、列表位置或标题年份补猜截止日期。
4. 中国政府采购网样本的地区字段没有从详情页可靠提取，保持未确认；不得从采购单位名称直接推断地区。
5. 广东省文旅和越秀来源的地区/分类仍是来源级提示，`confirmed=false`，必须在候选审核时回到详情页确认。
6. 中国政府采购网和越秀通知页包含普通采购、结果公示或非非遗主题事项；非遗相关性和行动性尚未确认，不能直接进入正式机会库。

## 4. DS1-C 门禁结论

### 通过

- 候选审计管线能够检查详情页、模板标记、重复、状态提示、来源层级和未确认字段；
- 没有模板污染和重复候选；
- 缺失字段没有被补猜；
- 每条候选均保留来源详情 URL 和来源 ID；
- 正式发布被全量阻断。

### 尚未通过

- 尚未完成逐条非遗相关性和“可行动机会”人工确认；
- 尚未完成申请方式、资格、预算、截止日期的逐字段核验；
- 尚未允许 DS1-D 批量正式发布。

**DS1-C 结论：通过候选审计门禁，但仅允许进入人工复核队列；正式发布门禁保持关闭。**
