# DS6 每三天只读调度设计 V1.0

DS6 将 DS2 → DS5 固化为可重复运行的一次性任务，并由外部调度器每 3 天触发。任务顺序为来源端点核验、DS2 只读发现、DS3 质量分层、DS4 发布候选审计、DS5 运营一致性验证。

## 安全边界

- `formal_store_write=false` 是硬门禁；
- 运行前后记录正式库 SHA-256，哈希变化即阻断；
- 失败只记录运行结果，不替换正式库；
- 候选必须等待 DS1-D 人工审批包；
- 连续三次通过后才允许进入 DS7 来源扩展。

调度配置见 [ops/ich-ds6-schedule.json](../../ops/ich-ds6-schedule.json)，运行账本见 [DS6-只读调度运行账本_V1.0.json](./DS6-只读调度运行账本_V1.0.json)。
