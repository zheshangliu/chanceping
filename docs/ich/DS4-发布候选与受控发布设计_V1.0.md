# DS4 发布候选与受控发布设计 V1.0

DS4 将正式机会库视为发布候选，执行只读审计：数据契约、动态状态、六类覆盖、来源等级、主来源唯一性、语义模板污染和发布可见性。审计脚本不会写正式库；正式写入仍必须沿用 DS1-D 的审批工作流和原子备份。

## 进入门禁

- DS1-D 已有可追溯的审批包和导入记录；
- DS2 只读发现与 DS3 候选质量记录均通过；
- 正式库可加载且校验通过。

## 退出门禁

- 当前有效机会不少于 30 条；六类均有当前机会；
- L1/L2 主来源比例不低于 80%；
- 主来源 URL 不重复、无语义模板污染；
- API、SSR、详情页、搜索和现有回归通过；
- `production_store_write=false` 的机器记录和报告已生成。

脚本：`npm run ich:ds4:release-audit`；验证：`npm run verify:ich:ds4`。
