# DS9 后台运营面板与运行指标设计 V1.0

## 目标

把 DS5.1—DS8 已产生的运行证据集中到 `/ich/admin`，让运营者能判断“数据是否在更新、哪些来源需要处理、哪些机会需要复核”，而不是只看到一个静态机会总数。

## 只读指标

- 正式机会库：总量、已发布量、按动态状态计算的当前/历史量、撤回量。
- 生命周期：`needs_recheck` 队列、DS8 门禁、主来源重复组、批次上限。
- 口径漂移：DS5 上次快照与当前按同一状态函数动态计算的结果并列展示，避免把历史快照误当成实时数量。
- 来源体系：DS1 注册来源、query pack 数量、来源运营状态、DS7 适配器/人工流程和六类覆盖。
- 调度运行：DS6 时区、三天周期、账本运行次数、最近运行门禁、正式库哈希是否保持不变。

## 安全边界

- 新增 `GET /api/internal/ich/operations`，沿用 `CHANCEPING_ICH_ADMIN_TOKEN` Bearer 认证。
- 未认证请求返回 401；未配置管理凭据时返回 503。
- 接口和页面只读，不提供候选晋级或正式库写入能力。
- 页面保持 `no-store`、`noindex`、CSP 与 frame 防护；不返回 token、IP、User-Agent 或环境变量值。

## 门禁

DS9 通过条件：正式库与来源注册非空、DS6/DS8 正式库写入均为 false、没有已知主来源重复组，且受保护接口、后台渲染和现有 ICH 回归测试全部通过。DS8 的 `pass_with_followups` 只作为面板告警展示，不会绕过人工复核。
