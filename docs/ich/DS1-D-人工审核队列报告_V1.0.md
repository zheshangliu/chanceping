# DS1-D 人工审核队列报告 V1.0

## 1. 队列目的

为避免把普通采购、结果公示或行业通知误当作非遗机会，本轮将 9 条候选拆为逐条人工审核任务。队列只保存审核输入和机器预检，不代表批准发布。

队列文件：[DS1-D-人工审核队列_V1.0.json](/Users/1sunflower/Documents/chanceping/docs/ich/DS1-D-人工审核队列_V1.0.json)。

## 2. 当前状态

| 指标 | 数量 |
|---|---:|
| 队列条目 | 9 |
| 待人工审核 | 9 |
| 已批准 | 0 |
| 正式机会库写入 | 否 |

机器预检只做提示：

- 标题含“采购、招标、征集、揭榜”等时标记 `possible_action`；
- 标题含“结果公示、中选结果、中标公告”等时标记 `result_or_closed`；
- 标题含“非遗、传统工艺、文旅、文创、博物”等时标记 `possible_ich_context`；
- 没有命中时标记 `unknown`，不判定为不相关。

## 3. 每条必须确认

1. 是否真正面向非遗手艺人、工作室、品牌或文创团队；
2. 是否仍可行动，而非结果公示或已结束事项；
3. 主办方、地区、截止日期、申请方式和资格；
4. 详情页是否存在直接证据；
5. 是否与正式库现有记录重复；
6. 通过 DS0 语义完整性和来源回溯门禁。

**本队列仍保持 `formal_publish_blocked=true`，没有任何自动批准路径。**
